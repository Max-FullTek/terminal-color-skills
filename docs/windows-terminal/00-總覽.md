## 目前 PowerShell profile 做了什麼

1. 把 `WinGet Links` 加到 PATH 前面，讓 winget 安裝的 CLI 優先被找到
2. 把 `WindowsApps` 加進 PATH，讓 `winget`、`oh-my-posh` 這類 alias 可以被找到
3. 只在互動式 shell 載入強化功能，避免腳本模式報錯
4. 載入 `PSReadLine`
5. 載入 `Terminal-Icons`
6. 初始化 `Oh My Posh`
7. 在 Oh My Posh 後初始化 `zoxide`
8. 設定 `fzf` 預設檔案來源為 `rg`
9. 初始化 `broot`，並建立 `b` alias 到 `br`
10. 載入 `Completions` 目錄下的補完腳本
11. 提供 `codex` 與 `copilot` wrapper

Windows Terminal、Oh My Posh、broot 是三層不同設定：

- Windows Terminal 使用 `Warm Sand` 色票
- Oh My Posh 使用 `OMP_THEME_NAME` / `omp-theme` 切換 prompt theme
- broot 使用自己的 `codex-muted-green.hjson` skin

## 每次改完怎麼套用

編輯完 profile 後，在 PowerShell 內重載：

```powershell
. $PROFILE
```

如果是改 Windows Terminal `settings.json`，通常存檔後 Windows Terminal 會自動套用；不行就重開分頁。

## 建議的修改原則

1. 優先改 profile，不要直接硬改系統層 PATH
2. 一次只改一個區塊，改完就 `. $PROFILE`
3. 有多行 init 腳本時，先接成單一字串再 `Invoke-Expression`
4. 互動式才需要的東西，盡量放在 `$isInteractiveShell` 區塊內
