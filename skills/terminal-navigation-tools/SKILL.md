# Terminal Navigation Tools

Use this skill after the profile core exists.

## Tools

Manage these tools together because their profile integration overlaps:

- `zoxide` for smart directory jumping
- `fzf` for fuzzy selection
- `ripgrep` as the preferred file source and search tool
- `broot` for interactive terminal file navigation

Do not reinstall removed tools such as `eza` or `yazi` unless the user asks.

## Install Or Verify

Prefer winget:

```powershell
winget install --id ajeetdsouza.zoxide --exact --accept-source-agreements --accept-package-agreements
winget install --id junegunn.fzf --exact --accept-source-agreements --accept-package-agreements
winget install --id BurntSushi.ripgrep.MSVC --exact --accept-source-agreements --accept-package-agreements
winget install --id Dystroy.broot --exact --accept-source-agreements --accept-package-agreements
```

Verify:

```powershell
Get-Command zoxide,fzf,rg,broot -ErrorAction SilentlyContinue
```

## Profile Integration

Add inside the interactive guard:

```powershell
function Invoke-ZoxideInit {
  param([switch]$Force)

  $zoxide = Get-Command zoxide -ErrorAction SilentlyContinue
  if (-not $zoxide) { return }

  if ($Force) {
    $global:__zoxide_hooked = 0
  }

  $zoxideInit = (& $zoxide.Source init powershell) -join "`n"
  if (-not [string]::IsNullOrWhiteSpace($zoxideInit)) {
    Invoke-Expression $zoxideInit
  }
}

Invoke-ZoxideInit -Force

if ((Get-Command rg -ErrorAction SilentlyContinue) -and (Get-Command fzf -ErrorAction SilentlyContinue)) {
  $env:FZF_DEFAULT_COMMAND = 'rg --files --hidden --follow --glob "!.git"'
  $env:FZF_CTRL_T_COMMAND = $env:FZF_DEFAULT_COMMAND
}
```

Do not pipe `zoxide init powershell` directly into `Invoke-Expression`. It emits a multi-line script; piping can execute blank lines and incomplete script blocks one at a time, causing Windows Terminal startup errors like "empty string" or "Missing closing '}'".

If Oh My Posh is also initialized in the profile, initialize Oh My Posh first and then run `Invoke-ZoxideInit -Force`. If an `omp-theme` helper reloads Oh My Posh in the current session, it should call `Invoke-ZoxideInit -Force` after reloading the prompt.

For broot, prefer the launcher generated by broot when it exists:

```powershell
$brootLauncher = Join-Path $env:APPDATA "dystroy\broot\config\launcher\powershell\br.ps1"
if (Test-Path $brootLauncher) {
  . $brootLauncher
  Set-Alias b br
}
```

If `broot --install` fails because Windows cannot create the launcher symlink, do not switch to another file manager or invent a different cd protocol. Use broot's official PowerShell function output as a fallback:

```powershell
broot --print-shell-function powershell
```

Then add the printed `br` function inside the interactive guard and keep:

```powershell
Set-Alias b br
```

Report clearly that the official launcher file is missing and the profile is using the official printed fallback.

## Broot Skin

broot has its own skin system. It does not automatically inherit the Windows Terminal `Warm Sand` color scheme.

Apply the bundled skin from this skill:

1. Create `%APPDATA%\dystroy\broot\config\skins` if needed.
2. Copy `references/codex-muted-green.hjson` from this skill directory to `%APPDATA%\dystroy\broot\config\skins\codex-muted-green.hjson`.
3. Back up `%APPDATA%\dystroy\broot\config\conf.hjson` if it exists.
4. In `conf.hjson`, set the dark/unknown skin import to:

```hjson
file: skins/codex-muted-green.hjson
```

If the config still says `file: skins/dark-blue.hjson`, the documented broot look has not been applied.

## Windows Terminal Dependency

The broot flow expects Windows Terminal to pass `Shift+Enter` as `ESC + Enter` and leave `Alt+Enter` unbound. Use `windows-terminal-appearance` for that keybinding setup.

## Validation

Run:

```powershell
. $PROFILE
Get-Command zoxide,fzf,rg,broot
zoxide --version
fzf --version
rg --version
broot --version
Test-Path "$env:APPDATA\dystroy\broot\config\skins\codex-muted-green.hjson"
Select-String "$env:APPDATA\dystroy\broot\config\conf.hjson" -Pattern "codex-muted-green"
broot --conf "$env:APPDATA\dystroy\broot\config\conf.hjson" --version
```

Then test interactively:

- `z <known-folder-fragment>`
- `fzf`
- `rg <known-text>`
- `b`
